## What changed

- Centralized canonical origin, contact email, metadata normalization and social metadata. Added route metadata and noindex layouts for private/utility routes. Preserved source canonicals for syndicated articles rather than claiming them as original work.
- Added article-specific branded share images, a default share image, working cover fallback, Android icons and manifest.
- Rebuilt public contact/newsletter/email-signup forms around shared accessible validation and busy/error states. Unified newsletter entry points so they persist subscriptions consistently. Contact handler checks Resend error objects and accepted IDs instead of assuming a resolved promise succeeded.
- Added success routes and non-personal confirmed-operation conversion events. Utility password flows use inline feedback and no longer use an alert dialog as success confirmation.
- Added analytics opt-in/preferences, disabled uncontrolled ad/Vercel tracking, and blocked newsletter campaigns until the verification/unsubscribe workflow is ready.
- Protected profile reading lists and added middleware authorization for admin API routes/uploads. Public comments no longer return email addresses. Removed the default legacy admin password and added upload type/size validation.
- Limited homepage story cards to 12, avoided loading article bodies for listing-only queries, fixed narrow-screen grids/header/search filters, corrected Tailwind dark mode to follow the selected theme, added focus/skip-link/reduced-motion support and coordinated the mobile CTA with consent/forms.
- Added persistent maintenance rules in `AGENTS.md` and recorded the initial audit in `audit/quality-baseline.md`.
